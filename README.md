Exhaustive documentation detailing the architecture, setup, and usage of the Code Inspector CLI utility, including static code analysis, dynamic code execution monitoring, and performance profiling for Python applications. The utility stores results in an SQLite database and generates interactive HTML reports. The architecture is modular, with the core logic in `src/core.py` and the CLI interface in `src/cli.py`. The test suite in `tests/test_core.py` ensures the core functionality works as expected.
